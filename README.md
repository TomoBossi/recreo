# recreo

A room for you and up to four friends: a video call, a chat, everyone's
cursors if you want them, and small games to play together — chess, connect
four, minigolf, silly stuff. Static, on GitHub Pages, with no server.

Built on [plaza](https://github.com/TomoBossi/plaza) (rooms, connections,
presence, channels) and [mirador](https://github.com/TomoBossi/mirador)
(camera, microphone, who is speaking, layout).
